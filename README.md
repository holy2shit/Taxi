# 🚕 TaxiFare — Система расчета стоимости поездки такси

Учебный проект по разработке настольного приложения с интеграцией реляционной базы данных. Программа автоматизирует расчет стоимости поездки на такси с учетом выбранного тарифа, расстояния, времени в пути и дополнительных коэффициентов, а также ведет учет выполненных заказов.

---

## 📋 Основной функционал
* **Расчет стоимости поездки:** автоматическая калькуляция цены по формуле (подача + километраж + время в пути) с учетом повышающего коэффициента (ночной тариф).
* **Работа с базой данных:** хранение справочников тарифов и водителей, а также сохранение истории всех рассчитанных заказов.
* **Учет и просмотр истории:** вывод журнала поездок в реальном времени с привязкой к водителю и тарифу.
* **Управление записями:** добавление новых расчетов и удаление ошибочных записей из базы.

## 🗄 Структура базы данных
В проекте используется реляционная база данных `TaxiDB`, состоящая из трех связанных таблиц:

| Таблица | Описание | Основные поля |
| :--- | :--- | :--- |
| **`Tariffs`** | Справочник доступных тарифов | `Id`, `Name` (Название), `BasePrice` (Подача), `PricePerKm` (Цена/км), `PricePerMin` (Цена/мин) |
| **`Drivers`** | База водителей и автомобилей | `Id`, `FullName` (ФИО), `CarModel` (Автомобиль), `LicensePlate` (Госномер) |
| **`Trips`** | Журнал выполненных поездок | `Id`, `TripDate` (Дата), `TariffId` (FK), `DriverId` (FK), `DistanceKm`, `DurationMin`, `IsNight`, `TotalCost` |

## 🚀 Инструкция по запуску
1. Склонируйте репозиторий на локальный компьютер:
   ```bash
   git clone https://github.com[ТВОЙ_НИК]/TaxiFare-Safiullin.git
   ```
2. Откройте файл решения `TaxiFareSafiullin.sln` в **Visual Studio**.
3. При необходимости обновите строку подключения (`ConnectionString`) к файлу базы данных `TaxiDB.mdf` в коде проекта.
4. Нажмите **F5** (или кнопку **Пуск**) для сборки и запуска приложения.
